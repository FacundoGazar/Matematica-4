## Determinar el dominio de las siguientes funciones:

**1.** f(x,y) = 1 / (x² + y²)

Como ambos términos del denominador son cuadrados (siempre va a ser ≥ 0), la única manera de que sumen 0 es que ambos sean 0. O sea, x = 0 e y = 0 simultáneamente.

D = { (x,y) ∈ ℝ² : (x,y) ≠ (0,0) }

---

**2.** f(x,y,z) = x² + 2y² − z²

Al ser un polinomio, el dominio es:

D = ℝ³

---

**3.** f(x,y) = x / (x² + y² − 9)

x² + y² − 9 = 0
x² + y² = 9

D = { (x,y) ∈ ℝ² : x² + y² ≠ 9 }

---

**4.** f(x,y) = y / (x² + y² + 1)

El denominador es una suma de un cuadrado más 1, por lo que siempre es ≥ 1, nunca puede ser 0.

D = ℝ²

---

**5.** f(x,y,z) = x² / (y² − z²)

y² − z² = 0
y² = z²

D = { (x,y,z) ∈ ℝ³ : y ≠ z }

---

**6.** f(x,y) = √(9 − x² − y²)

9 − x² − y² ≥ 0
x² + y² ≤ 9

D = { (x,y) ∈ ℝ² : x² + y² ≤ 9 }

---

**7.** f(x,y) = e^(−x² + y²)

La función exponencial está definida para cualquier número real como exponente.

D = ℝ²

---

**8.** f(x,y) = log(16 − x² − 16y²)

16 − x² − 16y² > 0
x² + 16y² < 16

D = { (x,y) ∈ ℝ² : x² + 16y² < 16 }
